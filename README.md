# 🧲 3D Galvanometer Simulation

โปรแกรมจำลองการทำงานของกัลวานอมิเตอร์ในรูปแบบ 3 มิติ (3D Galvanometer) ที่ออกแบบมาเพื่อการศึกษาและการเรียนรู้กลไกทางฟิสิกส์อย่างเป็นรูปธรรม โดยมีฟีเจอร์และภาพรวมการพัฒนาที่สำคัญดังนี้

## 🛠 1. โครงสร้างและการแสดงผล (Core Components)

- **ตัดเปลือกนอกออกเพื่อการเรียนรู้:** โฟกัสเฉพาะกลไกภายในที่สำคัญ โดยเอาตัวเครื่องและกระจกออก เหลือไว้เฉพาะหัวใจหลัก ได้แก่ แม่เหล็กถาวรขั้วเหนือ-ใต้, แกนเหล็กอ่อนตรงกลาง, ขดลวดเคลื่อนที่, เข็มชี้ขนาดยาวพิเศษ และสปริงก้นหอย
- **ระบุขั้วแม่เหล็กชัดเจน:** มีการทำพื้นผิวตัวอักษร **[ N ]** (สีแดง - ขั้วเหนือ) และ **[ S ]** (สีน้ำเงิน - ขั้วใต้) แปะติดบนตัวแม่เหล็กถาวร เพื่อให้ผู้ใช้งานมองเห็นขั้วและทิศทางของสนามแม่เหล็กได้ทันที
- **เข็มชี้ขนาดยาวพิเศษ:** ออกแบบเข็มให้มีความยาวเด่นชัด สามารถกวาดผ่านหน้าปัดสเกล (ที่มีเลข 0 อยู่ตรงกลาง) ได้อย่างชัดเจนจากทุกมุมมอง

## ⚡ 2. ระบบการเคลื่อนไหวสมจริง (Realistic Physics)

- **ฟิสิกส์สปริง-แดมเปอร์ (Spring-Damper Physics):** เมื่อผู้ใช้เลื่อนสไลเดอร์เพื่อเปลี่ยนค่ากระแสไฟฟ้า (mA) เข็มจะไม่เลื่อนไปแบบแข็งทื่อ แต่จะมีการตอบสนองอย่างสมจริง มีการสะบัด กระดอนเบาๆ (Wobble & Bounce) และมีแรงหน่วง (Damping) จำลองพฤติกรรมของเข็มเครื่องวัดแอนาล็อกของจริงได้อย่างสมบูรณ์แบบ

## 👆 3. ระบบโต้ตอบเพื่อการเรียนรู้ (Interactive Explanations)

- **ระบบสำรวจชิ้นส่วน:** ผู้ใช้สามารถใช้เมาส์คลิกหรือใช้นิ้วแตะที่ชิ้นส่วน 3D ชิ้นใดก็ได้ภายในโมเดล (เช่น ขดลวด, เข็ม, แม่เหล็ก, สปริง)
- **ผู้ช่วยอัจฉริยะ (Smart Assistant):** เมื่อเลือกชิ้นส่วน ระบบจะทำการไฮไลต์ชิ้นส่วนนั้น พร้อมกับแสดงคำอธิบายหน้าที่การทำงานผ่านกล่องผู้ช่วยอัจฉริยะที่ด้านล่างของหน้าจอทันที เพื่อเสริมสร้างความเข้าใจในแต่ละองค์ประกอบ
